# DesbloquearPainSpiderHeck
Instalación

Descarga el CompleteInstallAllPain.zip.

Opción A: no tengo Silk instalado

El zip incluye Silk, así que solo tienes que extraerlo en la carpeta del juego.

Abre Steam y ve a tu Biblioteca.
Haz clic derecho sobre SpiderHeck y selecciona Propiedades.
Ve a la pestaña Archivos instalados (o Local Files) y pulsa Examinar (Browse Local Files). Se abrirá la carpeta del juego, donde está SpiderHeckApp.exe.
Extrae todo el contenido del .zip dentro de esa carpeta. Si Windows pregunta si quieres reemplazar archivos, acepta.
Abre el juego desde Steam como siempre.

Al terminar, la carpeta del juego debería contener, junto a SpiderHeckApp.exe, los archivos winhttp.dll, doorstop_config.ini y la carpeta Silk.

Opción B: ya tengo Silk instalado

Solo necesitas copiar el mod.

Abre el CompleteInstallAllPain.zip y dentro de la carpeta nombrada Mods, se encontrará el archivo DesbloquearPain.dll
Luego pegalo en la carpeta Mods del juego.
Abre el juego desde Steam y buala, deberia funcionar.
